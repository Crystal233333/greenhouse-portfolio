# 花房作品集入口

星空花房浮岛为场景的单页作品集入口：**原图当场景，HTML / CSS / JS 只负责交互**。
没有 3D 建模、没有框架、没有构建步骤、没有任何联网依赖，双击 `index.html` 就能打开。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构 |
| `styles.css` | 全部样式（自适应、热点、卡片、动画、减少动态效果） |
| `app.js` | 热点生成、悬停提示、手机卡片、星空、视差 |
| `works.js` | **作品数据，日常只改这一个文件** |
| `scene.png` | 页面实际显示的图（见下方说明） |
| `reference.png` | 原始参考图，保持原样，页面不直接使用 |
| `preview/` | 各尺寸下的实际渲染截图 |

## 预览

直接双击 `index.html` 即可（`file://` 可用，不需要服务器）。

如果想用本地服务器看：

```powershell
# 在项目目录里任选其一
python -m http.server 8000
npx serve .
```

## 填写作品

打开 `works.js`，把 `name` / `summary` / `url` 的 `''` 换成真实内容即可：

```js
{
  id: 'sign',
  slot: '作品 1',
  subject: '右侧悬挂的圆形招牌',
  name: '',      // ← 作品名称
  summary: '',   // ← 一句话简介
  url: '',       // ← 访问网址，如 'https://example.com/xxx'
  hotspot: { left: '84.77%', top: '37.43%', width: '11.52%', height: '11.60%', shape: 'circle' }
}
```

规则：

- 留空 = 未配置。页面显示“尚未配置”，**不跳转、也不会出现任何编造的作品名或介绍**。
- 以 `#` 开头的链接同样视为未配置（不会把 `#` 当成有效作品链接）。
- 填好网址后，桌面端悬停显示作品名，点击在新标签页打开；手机端点按先出卡片，点“进入作品”才跳转。
- 外部链接自动带 `rel="noopener noreferrer"`。

### 热点位置

热点用**图片自身的归一化坐标**（0%~100% 对应整张图的宽高），与屏幕尺寸无关，所以任何窗口大小下都贴着物件。

```
left   = 热点左上角 x / 图片宽      top    = 热点左上角 y / 图片高
width  = 热点宽 / 图片宽            height = 热点高 / 图片高
```

当前数值对应参考图 729×724 上的像素位置：

| 物件 | 像素范围 | 配置值 |
| --- | --- | --- |
| 右侧圆形招牌 | x 618–702, y 271–355 | 84.77% / 37.43% / 11.52% / 11.60%（圆形） |
| 柜台右侧玻璃罩 | x 504–570, y 288–374 | 69.14% / 39.78% / 9.05% / 11.88% |
| 花房后方书架 | x 304–380, y 252–388 | 41.70% / 34.81% / 10.43% / 18.78% |

换图后按同一公式重算即可，页面无需其他改动。

## 关于 scene.png

`reference.png` 左上角烘焙着一个“01”编号，需要盖掉。做法是**只处理展示副本**：

- `reference.png` 一个像素没动，仍可作为原始素材；
- `scene.png` 由它复制而来，只用调和填充把“01”所在的那一小块夜空填平（原图其余部分完全一致）；
- 页面、模糊光晕层都只引用 `scene.png`，代码里没有任何遮盖补丁。

如果以后要换参考图：把新图另存为 `scene.png`（并同步 `index.html` 里的 `width` / `height`、`works.js` 里的热点坐标），若新图也有角标，重复一次填充即可。

## 动效范围

只做了三件低干扰的事，都可以单独去掉：

1. **星空粒子**（`app.js` 里的 `sky`）：画布上的缓慢漂移与闪烁，跟着指针做轻微视差。
2. **暖光呼吸**（`styles.css` 里的 `.glow-*`）：灯、玻璃罩、书架三处暖光缓慢明暗。
3. **场景漂浮 + 指针视差**（`.float` 动画 + `#tilt` 位移）：整场极轻微浮动与转动。

热点的位移和图片在同一个容器里，所以漂浮、视差、缩放都不会让热点脱离物件。
`prefers-reduced-motion: reduce` 下三项动画全部关闭，星空改为静态绘制。

> 花藤、灯具、花朵没有独立图层，**不能**独立运动。要单独动某株花，需要先拆图（另行处理）。

## 已验证 / 未验证

已在 Chrome 无头模式下用 CDP 实测：

- 1600×900、1024×700（中途缩放不刷新）、390×844、844×390 四种视口下，三处热点的相对位置与配置值完全一致，且不超出视口；
- 悬停提示位于视口内、键盘 Tab 有 2px 焦点环、触摸点按弹出卡片、Esc / 关闭按钮可关；
- 未配置时点击被拦截并给出轻提示，`#` 与空值都不产生链接；
- 配置真实网址后热点变为 `<a target="_blank" rel="noopener noreferrer">`，卡片里出现“进入作品”；
- 初始提示 7 秒后自动消失；减少动态效果下倾斜、漂浮、呼吸全部停止；
- 控制台无报错、无资源缺失。

未验证：真实手机（iOS Safari / Android Chrome）上的手感、微信等内嵌浏览器，以及接入真实作品网址后的跳转（当前数据全是未配置状态）。
