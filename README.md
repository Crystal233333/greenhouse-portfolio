# 花房 · 3D 作品集

当前页面是 Three.js 实时 3D 场景。以 `reference.png` 为视觉依据，保留滚动走近和物件点击交互。

## 预览

优先在本目录运行：

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8000/`。脚本和素材均在本地，无需安装依赖或执行构建。

可以双击 `index.html` 预览。当前场景不请求外部模型，主体、植物和道具均在本地程序化生成；浏览器的文件访问限制因环境而异，因此验收建议用本地服务器。

## 操作

- 首次打开先显示远景，并保留继续拉远的余量。
- 向下滚动：后退到浮岛全景。
- 向上滚动：走近花房。
- 右上角只保留喇叭图标，点击停止／开启声音；视距由滚轮和触摸滚动控制。
- 点击吊灯、书、花：先平滑推进并对准物品，再触发动画、打开对应作品面板；关闭面板后平滑退回点击前的视角。
- 画布获得键盘焦点后，按 1 / 2 / 3：依次操作吊灯、书和花；按 4 与小女孩打招呼。
- 小女孩站在圆凳右侧。近景和全景中均可点击她，镜头会靠近；她抬手挥动、微笑和轻轻歪头，约 3.2 秒后恢复站姿，镜头随后自动退回。她不打开作品面板。
- Esc：关闭作品面板。面板支持 Tab 焦点循环。
- 其他道具保留鸟笼、留声机、洒水壶、菌灯、捕梦网、萤火罐、花架等环境反馈。风铃按最新标注移除。
- 纯动画道具也会先聚焦，动作结束后自动退镜。聚焦期间暂停背景滚动，Esc 可以取消聚焦；物品间不会叠加镜头操作。

`index.html#overview` 直接打开最远全景，`index.html#inside` 直接进入近景。

## 本轮调整

- 花房由落地半圆棚改为直立侧墙与椭圆拱顶。补充柱脚、窗格、入口侧窗与后墙，拱顶保持玻璃通透。
- 柜台朝向入口，细化台面、门板、边框。圆凳增加车木腿和脚踏圈。
- 按用户最新标注，花架和鸟笼移到右侧，移除木天花板及柜台前突出的两根竖棍，留声机喇叭朝向观看者。物件的点击体同步移动，架上的盆栽跟随花架一起运动。
- 植物统一为曲面花瓣和叶片。紫藤集中于左前拱顶，花簇沿两侧和浮岛边缘分组。
- 增加后方工作台、陈列架与瓶罐，补充玻璃罩底座和吊灯铜肋。
- 木材、岩石和行星增加程序化纹理。修正颜色管理，加入环境反射，调整冷暖灯光和光晕。
- 浮岛增加不规则岩块，台阶移到前右侧，并增加支撑梁。细化水晶及远景取景。
- 相机在窄屏上后退，尽量保留场景宽度。渲染像素比上限为 1.5。
- 花叶使用三个实例化批次；不可动的同材质细节合并绘制。动态物件保留独立结构。
- 修复花朵展开后关闭面板无法收回，以及部分植物、蝴蝶点击标识不匹配的问题。
- 按用户后续修正，小女孩改为豆豆眼卡通造型：小黑眼点、简化鼻子、腮红和笑口。保留双马尾、花饰和白色花裙，不恢复原参考图的大眼睛。
- 星空新增蓝紫粉色银河、发光星尘、疏密星点、三组星宿连线和三颗远近不同的行星。星宿为装饰布局，不用于天文导航。

## 文件

- `index.html`：页面结构和本地脚本入口。
- `styles.css`：画布、控制按钮、作品面板和移动端样式。
- `projects.js`：作品名称、简介、标签和链接。日常填写作品只需编辑这个文件。
- `js/main.js`：渲染器、滚动、拾取、聚焦动作调度与面板。
- `js/camera-rig.js`：远近相机路径、平滑聚焦、取消、自动退镜与原视角恢复。
- `js/sky.js`：程序化银河、星尘、闪烁星点、星宿和行星。
- `js/world.js`：花房、浮岛、家具、灯光和道具摆放。
- `js/hover-glow.js`：交互物品的单点柔和悬停光，以及书本自身的暖色发光。
- `js/craft.js`：圆角几何、曲面花瓣、环境反射、实例化花叶及静态批次合并。
- `js/girl.js`：程序化人物、独立头部与手臂关节、表情、眨眼和打招呼动作。
- `js/cozy-nook.js`：白猫、矮垫、编织花篮，以及睁眼、抬头看向用户、重新入睡的动作。
- `js/textures.js`：程序化纹理。
- `js/interactions.js`：物件动画。
- `js/assets.js`、`js/vendor/GLTFLoader.js`：保留的模型加载管线。当前 `MODELS` 为空，不加载模型。
- `assets/models/`：旧版保留的模型文件，本轮未删除。
- `reference.png`：原参考图；`scene.png`：WebGL 不可用时的静态降级图。
- `girl-reference.png`：人物造型参考，不作为场景中的平面图片使用。
- `preview/girl-standing.png`、`preview/girl-greeting.png`：人物站立与打招呼姿态截图。
- `preview/cosmos-initial.png`、`preview/object-focus.png`、`preview/cartoon-girl.png`：新的初始远景、作品聚焦与豆豆眼人物截图。
- `preview/refined-inside.png`、`preview/refined-far.png`、`preview/refined-mobile.png`：本轮检查截图，以各文件生成时的版本为准。
- `legacy-2d/`：历史 2D 页面，保留不动。

《交接说明.md》下方的 2D 内容是历史方案。当前接手请以本文件和实际代码为准。

## 检查

可重复执行的几何、动画和射线拾取检查：

```powershell
node .taste-skill/verify-scene.cjs
```

该检查会验证三个作品动画、关闭后的复位、十二种环境动画、女孩连续两次打招呼与表情复位、电脑与手机比例下的主要拾取目标、有限几何坐标，以及可选模型缺失时能否构建场景。它不能代替浏览器画面或真实触摸测试。

本轮已在本地无头浏览器检查电脑远景、室内和 390×844 手机截图。真机帧率、iOS Safari 及真实作品网址跳转未验证，作品网址仍为空。

语法检查与几何、动画、拾取回归检查通过。最新标注调整后，额外检查了鸟笼、花架、留声机的点击体是否位于对应模型范围内，以及留声机动画结束后的喇叭朝向。

镜头专项检查覆盖：初始远景与最远距离的余量、镜头到达后才开始交互和弹框、关闭后恢复原位置与视角、重复点击保护、取消后不会迟到弹框、纯动画自动退镜，以及聚焦期间改变屏幕比例后的退镜。`preview/inspect-focus.html` 还在真实浏览器页面中执行聚焦、弹框、关闭、退镜和再次聚焦，并检查实际 DOM 状态。

本轮资源检查记录在 `.taste-skill/perf.json`：电脑与手机两种宽度合计 0 FAIL、2 WARN，警告均为 JavaScript 解析体积。此检查只采样一次；其中 CPU 软件渲染结果不能代表真实 GPU 帧率。该资源检查在最新标注微调期间运行，不作为微调后完整性能认证。

通用前端 Gate 原始结果为 `GATE: FAIL 1 (round 1 of 3)`。唯一布局项要求 `.wrap` 容器，这不适用于用户指定的全屏固定 3D 场景，已在 `.taste-skill/waivers.json` 说明。另有 `consistency.mjs` 超时，未声明通用 Gate 全部通过，也未重复运行该耗时检查。实际截图和专项回归检查单独完成。
